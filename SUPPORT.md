# Support

Report fork-specific issues at [WebUI Workbench Issues](https://github.com/nicoegerer/webui-workbench/issues). Do not send fork integration bugs directly to upstream without first reproducing them in the official application.

Include:

- Fork and Open WebUI runtime versions, OS and architecture.
- Local or remote Open WebUI server; local or GitHub workspace.
- Expected behavior, actual behavior and minimal reproduction steps.
- Connector type and a redacted error/log excerpt.
- Whether the issue occurs in a fresh profile or only after an upgrade.

Never attach configuration directories, tokens, chat databases or private health data. For security issues, follow [SECURITY.md](SECURITY.md).

Provider account authorization, quotas, subscriptions and outages belong to that provider. A connector's availability does not imply a free model subscription or guaranteed API access.

Support is community/best-effort. There is no paid plan, SLA or official provider partnership.
